Read & React Offense

Developed by Rick Torbett, the Read & React is a system of logical habits instead of set plays. When the ball handler performs an action, the rest of the team executes a corresponding reaction. It is taught through twelve progressive layers.

System Information

The Grinnell System

Created by David Arseneault at Grinnell College, this high-speed playbook turns basketball into a statistics game. It forces chaotic play tempo by prioritizing total shot numbers, defensive traps, and frequent team substitutions.

The 5 Core Principles

First Available Shot

Take the first open shot. If you can get a three-pointer within the first few seconds of a possession, shoot it without hesitation.

Ideal Shot Distribution

The mid-range shot is highly discouraged in this system. The focus is strictly on layups, dunks, and open three-pointers.
